# Product API Documentation

**Base URL**

```text
http://localhost:8080
```

| Chức năng                  | Method | Endpoint         | Request Body                                    | Status thành công | Status lỗi                     |
|----------------------------|--------|------------------|-------------------------------------------------|-------------------|--------------------------------|
| Lấy danh sách sản phẩm     | GET    | `/products`      | Không                                           | 200 OK            | 500 Internal Server Error      |
| Lấy chi tiết sản phẩm      | GET    | `/products/{id}` | Không                                           | 200 OK            | 404 Not Found                  |
| Thêm sản phẩm              | POST   | `/products`      | `{ "name":"Bút bi", "price":5000 }`             | 201 Created       | 400 Bad Request                |
| Cập nhật toàn bộ sản phẩm  | PUT    | `/products/{id}` | `{ "name":"Bút chì", "price":10000 }`           | 200 OK            | 400 Bad Request, 404 Not Found |
| Cập nhật một phần sản phẩm | PATCH  | `/products/{id}` | `{ "price":15000 }` hoặc `{ "name":"Bút màu" }` | 200 OK            | 404 Not Found                  |
| Xóa sản phẩm               | DELETE | `/products/{id}` | Không                                           | 204 No Content    | 404 Not Found                  |

---

## Ví dụ Response

### GET /products

```json
[
  {
    "id": 1,
    "name": "Bút bi",
    "price": 5000
  }
]
```

### GET /products/{id}

```json
{
    "id":1,
    "name":"Bút bi",
    "price":5000
}
```

### POST /products

```json
{
    "id":1,
    "name":"Bút bi",
    "price":5000
}
```
